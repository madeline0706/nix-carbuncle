# My personal niche blog :3

This is my self-hosted blog, running on a Raspberry Pi Zero 2W. The only modifications to the hardware are the addition of a 10/100 Ethernet + USB HAT, as well as a 32GB Micro SD card.

SSL and public access is configured on a VPS, traffic is proxied by Caddy. I would not recommend using this yourself, but I won't stop you!!!
